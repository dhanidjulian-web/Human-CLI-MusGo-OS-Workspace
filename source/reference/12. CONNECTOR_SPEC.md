Version: 1.0.0
Status: ACTIVE
Project: Human CLI

---

## 1. PURPOSE

Connector adalah lapisan integrasi yang menghubungkan aplikasi,
Agent, dan Workflow dengan layanan eksternal.

Connector digunakan untuk mengakses:

- GitHub
- VPS
- Cloud Storage
- URL/API
- Database
- SaaS
- layanan eksternal lainnya

Connector tidak bertugas sebagai Agent, Skill, Library, atau AI Provider.

---

## 2. CORE PRINCIPLE

Connector harus:

- modular
- reusable
- secure
- permission-aware
- credential-aware
- provider-independent
- mudah dikonfigurasi
- mudah ditambahkan
- mudah dinonaktifkan

User tidak perlu memahami implementasi internal Connector.

---

## 3. USER EXPERIENCE

Konfigurasi Connector harus sesederhana:

```text
Connector
    ↓
Connect
    ↓
Authenticate
    ↓
Ready

Untuk sebagian besar layanan, user cukup:

memilih Connector

login atau memasukkan credential

memberikan permission

selesai
```
