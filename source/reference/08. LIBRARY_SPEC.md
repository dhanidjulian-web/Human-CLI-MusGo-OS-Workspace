# 1. PURPOSE

Library adalah sistem penyimpanan dan retrieval knowledge yang digunakan oleh:

- Chat
- Agent
- Autonomous Workflow
- Code Generation
- Project Development
- Deployment
- Blueprint Reference

Library dirancang agar Agent tidak perlu membaca seluruh file knowledge.

Primary strategy:

INDEX FIRST

↓

RELEVANT ITEM

↓

FULL CONTENT ON DEMAND
