# 1. PURPOSE

Agent Orchestrator adalah komponen yang mengatur bagaimana Agent
menjalankan suatu task.

Orchestrator bertugas menghubungkan:

- User
- Profile
- Agent
- Prompt
- AI Router
- Skills
- Libraries
- Connectors
- Sandbox
- Workflow
- Memory
- Security Policy

Orchestrator bukan AI Provider dan bukan AI Model.

---

# 2. CORE PRINCIPLE

Agent Orchestrator harus:

- simple
- modular
- deterministic pada execution flow
- capability-aware
- permission-aware
- resumable
- observable
- failure-tolerant

Orchestrator tidak boleh memiliki ketergantungan langsung terhadap
provider AI tertentu.

---

# 3. PRIMARY RESPONSIBILITY

Orchestrator bertanggung jawab untuk:

1. menerima task
2. memahami Agent configuration
3. memuat Profile
4. menentukan capability yang diperlukan
5. memilih Skill
6. mengambil Library context
7. menentukan Connector
8. menentukan kebutuhan Sandbox
9. mengirim request ke AI Router
10. menjalankan tool/action
11. mengevaluasi hasil
12. melakukan retry jika diperlukan
13. menyelesaikan task
14. menyimpan execution state

---

# 4. NON-GOALS

Orchestrator tidak bertanggung jawab langsung untuk:

- menyediakan model AI
- menyimpan API key
- mengimplementasikan GitHub API
- menyimpan seluruh library
- menjadi database
- menjadi sandbox runtime
- menjadi workflow scheduler
- menjadi UI renderer

Fungsi tersebut dimiliki module masing-masing.
