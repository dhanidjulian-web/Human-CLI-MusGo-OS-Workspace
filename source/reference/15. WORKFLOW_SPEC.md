## 1. PURPOSE

Workflow System mengatur rangkaian pekerjaan Agent dari awal
hingga selesai.

Workflow menjadi orchestration layer yang menghubungkan:

- User
- Agent
- AI Router
- Skill
- Library
- Connector
- GitHub
- Sandbox
- Build
- Test
- Deployment
- Artifact
- Memory
- Approval

Workflow harus dapat menjalankan pekerjaan secara:

- manual
- semi-otomatis
- otomatis
- resumable
- retryable
- auditable
