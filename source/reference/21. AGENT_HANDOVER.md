## 1. PURPOSE

`AGENT_HANDOVER.md` mendefinisikan mekanisme perpindahan pekerjaan,
context, state, hasil, artifact, dan tanggung jawab antar-agent,
workflow, session, maupun human operator.

Tujuan utama:

- mencegah pekerjaan hilang ketika session berakhir
- memungkinkan agent lain melanjutkan pekerjaan
- menjaga context tetap terstruktur
- memisahkan temporary context dari persistent project state
- menyediakan handover yang dapat diverifikasi
- menjaga traceability setiap perubahan
- memungkinkan human mengambil alih pekerjaan kapan saja
