# 11. AUTO BYOK

MANUAL

atau

---

# 12. API KEY ROTATION

Jika provider mempunyai multiple API Keys:

MANUAL:

Gunakan satu key yang dipilih user.

AUTO:

Gunakan key secara otomatis.

Routing dapat menggunakan:

- round-robin
- random
- failure-based rotation
- quota-aware rotation

Jika key gagal:

1. catat failure
2. tandai key sementara unavailable
3. coba key berikutnya
4. lanjutkan request jika berhasil

Jangan menampilkan secret API Key dalam log.

---

# 13. MANUAL MODEL

MANUAL berarti:

User memilih tepat satu model.

Tidak boleh melakukan automatic model switching selama task berjalan kecuali:

- user mengaktifkan fallback
- model mengalami failure
- user memberikan izin

Model preference tidak boleh diganti secara diam-diam.
