# 9. LONG CONVERSATION

Human CLI harus dirancang untuk conversation panjang.

Masalah yang harus dihindari:

- UI semakin lambat
- seluruh conversation dimuat sekaligus
- RAM meningkat terus
- browser/webview-like freezing
- crash ketika membuka kembali conversation
- context window cepat penuh

Solusi:

- pagination
- lazy loading
- message virtualization
- local persistence
- context compaction
- summary
- selective context retrieval

---

# 10. CONTEXT MANAGEMENT

Conversation panjang tidak boleh memaksa user membuat chat baru.

Sistem harus mempertahankan:

- project context

- important decisions
- bookmarks
- recent messages
- agent state
- repository state
- workflow state

Context lama yang tidak penting dapat dikompaksi.
