## 1. PURPOSE

GitHub Module adalah integrasi khusus untuk mengelola repository
GitHub melalui Agent, Chat, Workflow, dan Autonomous Workflow.

GitHub Module digunakan untuk:

- membaca repository
- melakukan audit repository
- clone repository
- membuat branch
- membaca dan mengubah file
- membuat commit
- push perubahan
- membuat Pull Request
- membaca dan mengelola Issue
- melakukan development menggunakan Sandbox
- melakukan deployment workflow yang membutuhkan GitHub

---

## 2. CORE PRINCIPLE

GitHub harus diperlakukan sebagai external service.

GitHub bukan:

- Sandbox
- Library
- Skill
- AI Provider
- AI Model
- Memory

GitHub diakses melalui GitHub Connector.
