## 1. PURPOSE

Sandbox adalah lingkungan eksekusi terisolasi yang digunakan Agent
untuk menjalankan pekerjaan development, testing, build, analysis,
dan operasi repository tanpa langsung bekerja di environment utama
aplikasi.

Sandbox terutama digunakan untuk:

- clone repository
- menjalankan source code
- menjalankan build
- menjalankan test
- menjalankan lint
- menjalankan security scan
- membuat perubahan file
- memeriksa diff
- menghasilkan artifact
- menjalankan tool development
- melakukan eksperimen secara terisolasi
