## 1. PURPOSE

Memory System mengatur penyimpanan, pengambilan, pembaruan,
dan penghapusan informasi yang diperlukan oleh Agent,
Workflow, Project, dan User.

Memory digunakan agar Agent tidak harus mengulang seluruh
proses reasoning atau membaca ulang seluruh repository,
Skill Library, Blueprint Library, dan execution history.

Memory bukan pengganti:

- Library
- Skill
- GitHub
- Sandbox
- Database utama
- Artifact Storage

Memory adalah lapisan contextual persistence.

---

## 2. CORE PRINCIPLE

Memory harus:

- relevan
- minimal
- terstruktur
- dapat dicari
- dapat diperbarui
- dapat dihapus
- memiliki scope
- memiliki provenance
- memiliki retention policy
- tidak menyimpan secret secara sembarangan
