- user
- project
- repository
- AI provider
- API key
- GitHub credential
- connector
- sandbox
- library
- skill
- memory
- workflow
- artifact

sebuah module terpisah.

3. ZERO TRUST

Tidak ada component yang otomatis dipercaya hanya karena berada di dalam aplikasi.

Setiap:

Agent
Tool
Connector
Provider
Workflow
Repository
Sandbox

harus memperoleh permission sesuai kebutuhan.

4. LEAST PRIVILEGE

Setiap component hanya mendapatkan akses minimum yang diperlukan untuk menyelesaikan task.

11. TOOL DENY BY DEFAULT
