# CHAT ENGINE SPECIFICATION

Version: 1.0.0
Status: ACTIVE
Project: Human CLI

---

# 1. PURPOSE

Chat Engine adalah mesin percakapan utama Human CLI.

Chat Engine bertanggung jawab untuk:

- menerima input user
- mengelola conversation
- membangun context
- memanggil AI Router
- menerima streaming response
- menjalankan tool/agent request
- mengelola cancellation
- menangani retry/fallback dari AI Router
- menyimpan message state
- meneruskan task ke Agent Orchestrator
- menjaga pemisahan antara chat biasa dan autonomous execution

Chat Engine bukan AI Provider.

Chat Engine tidak memilih provider secara langsung.
