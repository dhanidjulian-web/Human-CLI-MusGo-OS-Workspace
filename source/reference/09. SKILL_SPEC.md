# SKILL SPECIFICATION

Version: 1.0.0
Status: ACTIVE
Project: Human CLI

---

# 1. PURPOSE

Skill System adalah sistem untuk menyediakan kemampuan, instruksi,
prosedur, dan knowledge operasional yang dapat digunakan oleh:

- Agent
- Chat
- Autonomous Workflow
- Agent Orchestrator

Skill bukan model AI.

Skill bukan Agent.

Skill bukan Connector.

Skill adalah reusable capability/instruction package yang dapat dipanggil
ketika sebuah task membutuhkan kemampuan tertentu.

---

# 2. CORE PRINCIPLE

Skill harus bersifat:

- modular
- reusable
- discoverable
- versionable
- independently manageable
- permission-aware
- source-independent

Agent tidak perlu memuat seluruh skill library.

Strategi utama:

SKILL INDEX

↓

FIND RELEVANT SKILL

↓

LOAD SKILL

↓

EXECUTE / APPLY SKILL

---

# 3. SKILL VS AGENT

Agent:

- memiliki identity
- memiliki task
- memiliki prompt
- melakukan orchestration
- memilih dan menggunakan skill

Skill:

- menyediakan capability/instruction
- dapat digunakan banyak Agent
- tidak memiliki conversation lifecycle
- tidak memiliki identity sendiri

---

# 4. SKILL VS LIBRARY

Library:

knowledge/reference/blueprint.

Skill:

capability/instruction/procedure.

Contoh:

Library:

"Architecture blueprint untuk authentication."

Skill:

"Audit authentication implementation."

---

# 5. SKILL VS CONNECTOR

Connector:

akses ke external service.

Contoh:

GitHub Connector.

Skill:

instruksi bagaimana melakukan pekerjaan.

Contoh:

GitHub Repository Audit Skill.

Flow:

Agent

↓

Skill

↓

Connector

↓

GitHub

---

# 6. SKILL VS MCP

MCP adalah protocol/interface untuk menyediakan tools/context
kepada AI system.

Skill tidak membutuhkan MCP.

Skill dapat menggunakan MCP jika capability tersebut memang
menggunakan MCP-based tool.
