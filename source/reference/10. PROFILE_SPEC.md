Version: 1.0.0
Status: ACTIVE
Project: Human CLI

---

# 1. PURPOSE

Profile adalah konfigurasi tingkat pengguna yang menentukan bagaimana
Agent, AI Provider, Model, Skill, Connector, Library, dan Workflow
digunakan.

Profile berfungsi sebagai:

- identity configuration
- behavior configuration
- capability configuration
- model preference
- skill access configuration
- connector access configuration
- library access configuration
- security preference
- orchestration preference

Profile bukan Agent.

Profile adalah konfigurasi yang dapat digunakan oleh satu atau banyak Agent.

---

# 2. CORE PRINCIPLE

Profile harus:

- sederhana
- reusable
- editable
- versionable
- permission-aware
- independent dari provider tertentu
- independent dari model tertentu

User tidak perlu membuat konfigurasi teknis berulang kali untuk setiap Agent.

---

# 3. PROFILE HIERARCHY

Recommended hierarchy:

User

Profile menjadi baseline configuration.

Agent dapat menggunakan atau mempersempit konfigurasi Profile.

# 4. PROFILE VS AGENT

Profile:

Menentukan environment dan preference.

Menentukan identity, role, objective, dan orchestration behavior.

Musgo Developer
